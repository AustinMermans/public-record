# SEC ownership transactions

Public Record reads the raw XML for selected SEC Forms 4 and 4/A. The underlying [SEC submissions API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) identifies the requested registrant CIK, accession, filing date and primary document; that registrant is not necessarily the issuer named by a Form 4. The display-only `xslF…/` path is removed to request the raw XML within the same exact accession directory. Each response is retained under its SHA-256 hash and re-parsed during the publication build. The ownership XML supplies the actual issuer CIK, which must match the covered company for this issuer-own-share reader; an accession's leading CIK can belong to a reporting owner or filing agent instead.

Each visible transaction is identified by issuer CIK, accession, non-derivative or derivative table, and row position. Multiple reporting owners on one filing remain a list attached to those rows; we do not multiply a transaction by the number of owners. The reader shows the reported security, code, acquisition/disposition direction, shares, price per share, direct/indirect ownership, transaction date, filing date and row footnotes. Shares and prices are the strings reported in XML. We do not aggregate them into dollar flows, unique buyer counts, ownership percentages or a trading score.

The default reader leads with the latest selected verified filing for each of six distinct issuers, followed by the chronological transaction-row ledger. The overview is a cross-company navigation aid, not a materiality ranking, and each card opens its exact filing and SEC XML. Company and transaction filters apply to the row ledger; the overview is omitted once either filter is active.

The purchase filter includes derivative and non-derivative rows coded `P` with acquisition code `A`; the table and security type remain visible on each record. [SEC's code list](https://www.sec.gov/edgar/searchedgar/ownershipformcodes.html) defines `P` as an open-market **or private** purchase of either type of security; the code cannot establish venue. `S` may also be open-market or private. Awards (`A`), conversions (`C`), exercises (`M`) and shares delivered or withheld for tax/exercise price (`F`) are not recast as discretionary buying or selling. A filing-level Rule 10b5-1 indicator is labeled at filing level, not attributed to each row. Footnotes can materially qualify the economics; open the SEC filing for full context.

Forms 4/A remain separate from original Forms 4. We do not infer which earlier rows they replace or add their quantities to the originals. The selected universe is 25 CIK-verified registrants and, within each, at most 12 recent ownership forms from the SEC recent-submissions payload. Some selected submissions concern a **different issuer** because the covered company is a reporting owner (for example, Berkshire Hathaway's filing about Lennar). Those XML sources are retained and labeled `other_issuer`, but excluded from this issuer-own-share transaction reader. They are not failed downloads or silently mixed into the company's own-share rows. This is neither a market-wide insider-trading screen nor a complete filing history. If an XML file cannot be fetched, parsed or reconciled, the source ledger marks partial coverage and the site does not invent transaction rows. Verified old accessions are cached and revalidated against retained bytes during every build; new selected accessions are fetched sequentially at no more than about two requests per second with the authorized identifying User-Agent.

The original filing and raw XML remain the governing disclosure. Public Record's scoped reuse licenses apply to its original software, writing and visualizations, not third-party filer prose or SEC marks. The [SEC's access policy](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data) governs automated retrieval. This display is factual research context, not investment advice or a conclusion about securities-law compliance.
