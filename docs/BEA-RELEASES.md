# BEA GDP release record

Public Record reads the [BEA release schedule](https://www.bea.gov/news/schedule/full) to discover dated GDP news releases with an actual `View` link, then verifies the matching [BEA release page](https://www.bea.gov/news/2026/gdp-second-estimate-and-corporate-profits-2nd-quarter-2026). A future schedule entry is not a publication. The collector does not use a forecast, a current interactive table or a FRED observation as a substitute for a dated release. No BEA API key is required for this bounded HTML collection.

The stage record is for **real GDP percent change from the preceding quarter, at a seasonally adjusted annual rate**. A displayed value is assigned to its target quarter, estimate stage and BEA publication date; a raw-response hash, extraction locator, retrieval clock and direct release URL travel with it. The reader compares only adjacent published stages of the same target and definition. A change in the published estimate is not a change in the economy's growth between quarters. The latest revised GDPC1 history arrives separately through FRED and may reflect subsequent annual or benchmark updates.

Displayed tenths are not exact underlying rates. BEA's [2026 Q2 second estimate](https://www.bea.gov/news/2026/gdp-second-estimate-and-corporate-profits-2nd-quarter-2026) shows 1.5% for both advance and second estimates but reports a downward revision of less than 0.1 percentage point in its technical note. Public Record therefore says the two *published values* are the same at shown precision and preserves BEA's qualified revision; it never converts that pair into an exact zero revision. [2026 Q1](https://www.bea.gov/news/2026/gdp-second-estimate-and-corporate-profits-1st-quarter-2026) gives a displayed 2.0% advance to 1.6% second estimate, a 0.4-percentage-point decline in the published estimate. Real GDI missing in an advance release stays missing, not zero.

Coverage begins with recent releases discoverable from the official schedule, not all historical first releases. BEA says links from old news releases to its interactive tables will reflect newer estimates; Public Record uses the dated release body and retained source bytes for the values it displays. A later edit to a BEA news page could affect a subsequently captured HTML copy, so the retrieval clock and hash are evidence of what was fetched, not proof that current HTML bytes are identical to first-publication bytes. A failed fetch retains a stale prior success; it does not turn an unverified scheduled item into an actual result. [BEA's citation guidance](https://www.bea.gov/help/guidelines-for-citing-bea) and [linking policy](https://www.bea.gov/about/policies-and-information/linking) govern attribution and reuse. Public Record is not affiliated with or endorsed by BEA.
